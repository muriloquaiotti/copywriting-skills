# Trabalho neste repositório

Este repositório distribui uma skill autossuficiente de copywriting em português. O ponto de entrada é [skills/copywriting/SKILL.md](skills/copywriting/SKILL.md).

Para tarefas de criação ou revisão de copy, leia a skill e apenas as referências pertinentes. Para manutenção do pacote, preserve a instalação sem dependências externas, links relativos, atribuição das fontes e os limites das edições.

Depois de alterações, execute `python3 scripts/validate.py`. Se alterar o instalador, verifique instalação nova, repetição sem mudanças, recusa de sobrescrita e substituição com backup num diretório temporário.

Não adicione PDFs, textos integrais extraídos, credenciais, bibliotecas particulares do projeto de origem ou caminhos absolutos pessoais ao pacote. Não declare resultados de conversão sem dados de teste.
