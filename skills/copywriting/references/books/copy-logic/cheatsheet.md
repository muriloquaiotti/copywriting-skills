# Guia de decisão

| Problema | Método / ação | Evite |
|---|---|---|
| A abertura não desperta vontade de ler | Alternativas de headline/lead; Peer Review quando houver grupo | Debate abstrato sobre “boa escrita” |
| Lead abaixo do corte escolhido | Parar o polimento e buscar abordagem nova | Gastar a sessão inteira em remendos |
| Reação de C | Cortar, especificar, simplificar | Manter jargão e adicionar adjetivos |
| Reação de U | Cortar ou comprovar cada alegação | “Eu sei que parece impossível” como única prova |
| Reação de B | Cortar ou condensar; avançar para informação relevante | Repetir o problema que o público já conhece |
| Há dados, mas o vendedor parece desconhecido | Acrescentar credenciais pertinentes | Confundir resultado do produto com confiança no fornecedor |
| Há um especialista, mas faltam resultados demonstrados | Buscar prova das alegações | Usar currículo como prova de tudo |
| Só existe análise de um agente | Nomear revisão individual | Inventar painel, votos ou pesquisa |

Escala do protocolo: 1 definitivamente não lê · 2 provavelmente não lê · 3 lê com ceticismo · 4 lê com interesse. Critério original de corte: 2,8 (Masterson), com variante 2,5 (Forde). Esses números não são previsões estatísticas.
