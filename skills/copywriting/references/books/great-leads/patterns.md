# Procedimentos

## Escolher a abertura
**Quando:** começar uma nova peça.
**Como:** consciência + confiança + ceticismo → direto/indireto → tipo de lead → ideia central → prova → ponte.
**Trade-off:** indireção pode abrir interesse e também atrasar a compreensão. Consulte ch02–03.

## Oferta que pode liderar
**Quando:** leitor já deseja o produto.
**Como:** condição atraente → benefício → detalhes coerentes → razão real → como aproveitar.
**Trade-off:** um brinde pode atrair compradores sem interesse na solução. Consulte ch04.

## Promessa calibrada
**Quando:** o resultado é desejado e a audiência está receptiva.
**Como:** função real → benefício distintivo → desejo → prova; reduza intensidade se a afirmação exceder a sustentação.
**Trade-off:** especificidade sem evidência aumenta a suspeita. Consulte ch05.

## Reconhecimento e esperança
**Quando:** o problema já ocupa a atenção.
**Como:** situação reconhecível → emoção → possibilidade de solução → razão para continuar.
**Trade-off:** insistir demais no problema produz tédio ou rejeição. Consulte ch06.

## Curiosidade com entrega definida
**Quando:** há informação útil que a pessoa ainda não conhece.
**Como:** benefício + lacuna → pistas relevantes → prova de pertinência → explicação no ponto informado.
**Trade-off:** suspense vazio deteriora confiança. Consulte ch07.

## Declaração ou história
**Quando:** o caminho indireto é apropriado.
**Como:** use um achado documentado para revelação; ou personagem/conflito/mudança para história. Em ambos, construa a ponte até o mesmo benefício central.
**Trade-off:** informação ou narrativa sem conexão com o produto atrai atenção sem intenção. Consulte ch08–09.
