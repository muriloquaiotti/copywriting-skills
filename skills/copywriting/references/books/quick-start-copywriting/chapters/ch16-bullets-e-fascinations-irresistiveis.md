# 16. Bullets e fascinations irresistíveis

Fonte: Quick Start Copywriting — Volume 2, capítulo 16. Páginas do PDF: 41–76.

## Preparação
Leia o produto e registre informação, localização, utilidade e evidência. Produza alternativas suficientes para selecionar as melhores. A prática de escrever sete vezes mais bullets que os utilizados é um exercício citado, não uma quantidade obrigatória em toda tarefa.

## Vinte e uma formas
| Forma na fonte | Aplicação operacional |
|---|---|
| How to | Mostrar como obter um benefício. |
| Secret to | Explorar informação pouco conhecida que realmente exista. |
| Why | Explicar uma causa relevante. |
| What | Indicar o que fazer ou descobrir. |
| What NEVER | Apontar um erro real e como evitá-lo. |
| PLUS | Acrescentar um benefício complementar. |
| Number | Organizar uma quantidade concreta de passos ou descobertas. |
| Right … WRONG! | Contrastar uma crença com evidência que a corrige. |
| WARNING | Alertar sobre um risco documentado. |
| Are you …? | Fazer o leitor reconhecer uma situação pertinente. |
| Gimmick | Dar um nome memorável a um procedimento real, ligando mecanismo e benefício. |
| Sneaky | Explorar um elemento oculto, negligenciado ou pouco conhecido, sem inventar ocultação intencional. |
| Statement of Interest + Benefit | Unir um fato interessante à utilidade para o leitor. |
| Direct Benefit | Declarar diretamente o ganho relevante. |
| Specific Question | Abrir uma pergunta específica que o conteúdo responde. |
| If … Then | Relacionar uma condição verdadeira a um benefício possível. |
| When | Mostrar o momento relevante para agir ou obter o benefício. |
| Quickest, Easiest | Destacar rapidez ou facilidade demonstrável, sem superlativo sem prova. |
| Truth | Esclarecer uma dúvida ou controvérsia com evidência. |
| Better | Comparar com uma alternativa segundo um critério verificável. |
| Single | Concentrar a atenção num fator ou ação importante. |

## Seleção e Makepeace Makeover
Pergunte: o benefício ficou específico? Há credibilidade pertinente? Existe motivo real para agir no prazo mencionado? Varie abertura, extensão e grau de revelação. Um bullet aberto entrega a informação; um blind bullet preserva uma resposta disponível no produto. Curiosidade sem benefício vira charada.

## Exemplo hipotético
Aberto: “Divida a proposta em escopo, entregáveis e condições para facilitar a revisão.” Blind: “A pergunta de briefing que revela uma dependência esquecida antes de você fechar o escopo — com exemplo no módulo 2.” Use o segundo apenas se módulo e exemplo existirem.

## Falhas
Inventar descobertas, páginas, exclusividade ou números; copiar alegações médicas/financeiras dos anúncios históricos; repetir a mesma fórmula até perder contraste.
